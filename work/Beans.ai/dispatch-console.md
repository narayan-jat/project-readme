# 🚚 Smart Dispatch & Route Management System

## 📌 Overview

Built and enhanced a logistics-focused dispatch system with real-time route visualization, stop management, and operational dashboards.

---

## 🚀 Key Features

### 🔹 Route Visualization

* Live status map with dynamic updates
* Route stop sorting:

  * Actual sequence
  * Time windows
  * Creation time

### 🔹 Kanban Dashboard

* Custom Kanban board for route tracking
* Multi-column card layout with sorting
* Performance-optimized rendering

### 🔹 Manifest & Stop Enhancements

* Express stop identification via business logic
* Dynamic map pin rendering based on attributes
* Territory configuration upload (ZIP + suburb parsing)
