# 🧠 Automatic Passenger Counter (Computer Vision System)

## 📌 Overview

Developed and contributed to an AI-powered Automatic Passenger Counter (APC) system during an internship at a mobility-tech company. The system leverages computer vision to accurately detect and count passengers inside vehicles in real-time.

---

## 🎯 Problem Statement

Manual passenger counting is:

* Error-prone
* Inefficient
* Not scalable for large transport systems

The goal was to build an **automated, accurate, and scalable passenger counting system** using image processing and machine learning.
