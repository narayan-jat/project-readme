# 🌐 Website Development & SEO Optimization (PurpleSigma)

## 📌 Overview

Developed and optimized a company website from scratch, focusing on frontend architecture, SEO performance, and production deployment.

---

## 🚀 Key Contributions

### 🔹 Frontend Development

* Designed and implemented responsive UI using:

  * React fundamentals
  * Bootstrap & Tailwind CSS
* Built reusable UI components (carousels, layouts)
* Improved visual presentation of low-content pages through design research

### 🔹 Backend Integration

* Used Django (REST APIs) to support dynamic content
* Connected frontend with backend APIs for data-driven UI

### 🔹 SEO Optimization

* Applied search engine optimization techniques:

  * Metadata structuring
  * Content positioning
  * Performance improvements
* Successfully improved visibility and ranking on search engines

### 🔹 Deployment

* Deployed applications on:

  * AWS (production hosting)
  * Vercel (early-stage deployment)
* Managed end-to-end deployment lifecycle
